# Проверка 2.7.0

Проверка выполнена в Chromium с настоящим кодом формуляра и моста кабинета. Все запросы браузера перехватывались; корзина Tilda заменена тестовой реализацией её публичных функций. Проверка не создавала заказов и не меняла действующий сайт.

Все 39 браузерных проверок пройдены на окончательных собранных файлах. Синтаксис обоих JS-файлов и разбор CSS прошли без ошибок. Машинный отчёт: `docs/verification-results.json`.

Проверены разные SVG всех 42 нот, пустое поле названия и сохранение собственного названия, сворачивание отдельных нот и всех групп, сохранение суммы состава, повторяющаяся нота на разных этапах смешивания, выравнивание навесок, редактирование десятичных долей, клавиатура и мышь на закреплённом ползунке, переход к первому компоненту, сохранение DOM кнопок и полей при пересчёте, отсутствие горизонтального переполнения на ширине 390 px.

Проверена передача картинок из разных форм галереи и из варианта товара, пустая картинка, реальный публичный ответ API для Orange EO, восстановление настройки автооткрытия корзины в родительском документе, доставка события обновления, отказ при отсутствии остатка, откат при ошибке массового добавления, скачивание Excel и PDF. Снимок публичного ответа Orange EO используется только как тестовая фикстура; цена и наличие всегда запрашиваются заново действующим кодом при добавлении.

Отдельно сравнены вычисления v2.6.0 и v2.7.0 на текущем публичном каталоге из 1148 материалов и запаховых профилях. Для двух настроек (100 г / 30% / шаг 0,01 г и 50 г / 20% / шаг 0,001 г) результат генерации 25 строк и полный расчёт IFRA совпали. Справочник и химические пределы в этой доработке не редактировались.

Это локальная проверка интерфейса и контракта интеграции. После установки трёх файлов требуется проверить страницу реального кабинета с установленной там версией корзины Tilda. На действующий сайт эта версия ещё не загружалась.
